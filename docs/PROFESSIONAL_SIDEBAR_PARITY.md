## 固定工作区交互（r10）

- 最右侧按钮轨只控制其左侧唯一的 `market-side-workspace`，行情页不再创建覆盖 K 线的第二层浮动抽屉。
- 点击当前已选按钮会收起整个数据工作区，K 线立即扩展；点击另一按钮会切换内容并强制展开工作区。
- 盘口、资讯、资金、分析、特色、ETF 与 Ace Agent 在同一列中互斥切换，读取同一份当前币种与报价。
- 下单按钮独立控制工作区下半部；关闭下单区后，上方数据区保持打开。盘口价格回填时会自动展开同一工作区中的下单区。
- 工作区展开时占用从页面操作栏到行情内容区的完整垂直列；“快照 / 保存布局 / 新建”左移到图表区上方，工作区收起后自动回位。
- 所有工作区数据内容直接顶到全局顶部栏下方；左边界提供弱显示收起把手。
- 下单区横挡板支持上下拖动，数据区占比限制为 28%–76% 并持久化；双击挡板恢复 58% 默认布局。
- 加预警打开当前币对的预警中心；自选按钮写入同一份本地自选状态；主力与简况仍在同一工作区内切换。

## 交易安全边界

- 未授权时只显示功能说明和授权入口。
- 抢新开盘、多账户下单、三键下单、智能拆单和画线下单只保存本地草稿或本地模拟记录。
- 不上传 API Key，不自动授权，不向交易所发送委托，不由 AI 直接执行交易。
