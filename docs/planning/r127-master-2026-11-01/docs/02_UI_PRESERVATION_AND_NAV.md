# 02｜r127 现有 UI 保真契约与页面地图

## 0. 全局设计要求

- **唯一有效 UI 为现有 React/Vite `src/`**。禁止创建另一套 Next.js/模板仪表板替换之；禁止删除导航、子标签、功能入口及现有图表组件。
- 保持用户五张截图展示的**浅色专业金融终端**：极窄左图标栏、顶部工具/搜索、主工作区、右侧快捷工具及可展开 Agent 面板、底部系统/交易状态；支持日后深色模式，但不影响默认浅色基线。
- 三栏是可切换的工作区状态，不是强制每页都显示：左侧 60–70px 主导航、主工作区自适应、右侧 Ace Agent 大约 320–420px 可固定/关闭/缩放；图表支持底部交易面板高度调整、保存工作区布局。
- 所有数字金额与价格使用稳定小数精度、等宽数字、右对齐；控件风格统一，重要操作前进行真实结果预览。
- 大量功能必须通过二级频道/面板/命令栏渐进呈现；不要因为按钮多而整批删除。
- `src/main.jsx` 将来允许逐步拆分，但**每次变更前后用固定截图、DOM 语义、回归测试比对**；不能重写 `main.jsx` 导致行为缺失。

## 3. 当前页面与 Agent 的动作契约

- **首页**：Web3/股票切换 → 正确变更搜索和导航上下文；输入问句 → 直接搜索或创建可跟踪研究任务；没有 Key 显示配置入口；不能输出默认模板当真实结论。
- **行情/图表**：任意当前 symbol/venue/timeframe/chart-selection → `selectedContext`；Ace Agent 显示已附带的真实 OHLCV 范围；点击“分析”创建 Task；点击“标记图表”回到同时间范围与绘图图层；交易按钮打开现有 UI 风格票据而非打开另一套独立系统。
- **快讯/要闻**：事件与证券/币对关联必须有证据标志（自动关联不等于已验证影响）；选择一条新闻后 Ace Agent 显示可引用来源快照和发布时间；离线保留缓存及醒目来源失效提醒。
- **策略**：手写笔记可直接生成结构化策略草稿，但分析 AI 不可以伪造回测；脚本警报需可以保存/启用/禁用并获得真实任务状态，保存笔记后关联真正策略 ID 和后端历史。
- **资产**：点击一笔持仓 → Agent 自动理解此持仓的当前风险敞口、原始 Thesis、未成交订单及其来源；展示真实账户连接状态，不能混合模拟资产。
- **授权**：read-only 与 trade-enabled 权限必须两套独立流程，用户需要明确知道 API Key 是否能交易、是否有提币权限（必须禁止提现权限）。
- **全球命令栏**：能检索标的、跳页、搜索功能、唤醒 Agent、创建提醒、打开交易票据；危险操作永远需要确认与服务端校验。

## 4. 组件与布局规范

- `AppShell`：导航、顶部搜索、状态栏、右侧工具条、弹层管理；现有布局优先通过适配器集成，不要求首期重写。
- `WorkspaceContext`：account, execution_mode, asset_class, venue, symbol, timeframe, selection_range, data_snapshot_id, thesis_id, strategy_id, order_id。所有字段带更新时间与来源。
- `AceAgentDock`：本来就有的右面板升级为 `Chat / Team / Actions / Tasks` 四个视图；可收起、固定、拖动宽度、折叠任务；鼠标与键盘同等支持。
- `OrderTicket`：现有交易区域增强为对称买/卖票据，支持 LIMIT/MARKET 基本单型；展示数量单位、账户、交易模式、估算费用、风险预览和最小交易量；只接受服务端成功/未确认状态。
- `OrdersBottomPanel`：可折叠、保留表格排序、过滤账户/模式/交易所、持仓、成交、通知、Agent Task；图表与底部互不遮挡。
- `EmptyErrorSkeleton`：Loading、Empty、Disconnected、Unauthorized、Stale、PartialFailure、Demo、Paper、Live 状态统一组件；来源级错误可局部重试。

## 5. UI 不允许回归的关键路径

1. 现有导航所有频道可访问、刷新保留；图表横向/多窗口调整、指标、画线、保存、导入/导出、脚本、回放仍可用。
2. Ace Agent 展开不压碎主图，关闭后主图自动扩展；布局设置刷新/重登后仍保留。
3. 任意点击“生成策略/交易提案”只能产生可编辑草稿，不能自动提交真实订单。
4. 快讯/要闻断网时原位显示已缓存时间与重试，不能展示一个永远加载的空白页面。
5. 用户能明确区分“WebSocket 行情实时”与“交易所账户真实连接”是两种不同状态。
