# 14｜历史产品决策与本次“保留 UI”修正

## 已达成的产品决策

| 主题 | 原来反复出现的诉求 | 统一结论 |
|---|---|---|
| 定位 | “Agent 的彭博”、专业、顶尖且易用 | AI-native professional trading terminal，不是纯 AI 聊天或单一投研助手 |
| 多资产 | 股票、ETF、CEX、Web3 | 一个平台统一研究、账户与投资记忆，但交易规则/券商身份独立 |
| AI 参与 | 持续多 Agent、及时便捷、右侧 Copilot | Agent 嵌入现有工作区、直接理解图表/资讯/策略/资产上下文；有持续任务和主动提醒 |
| UI | 旧 UI 太复杂、按钮无效；现在 r127 的专业布局已形成 | **保留最新已开发 UI**，优化动线和信息密度，不能为了“简洁”做功能缩水版 |
| 实盘 | 此前阶段性不做全自动实盘；当前明确要能真实交易 | 真实手动交易为第一成熟标志，自动交易后置且有权限/额度/审批/风险网关 |
| 开源借鉴 | Hummingbot、TradingAgents、Fincept、OpenBB、Vibe-Trading 等 | 复用成熟组件，避免五套策略/执行系统互相竞争；具体许可审计 |
| 技术 | 不做 Kubernetes/HFT、不浪费大量开发成本 | FastAPI + React + Postgres/Redis 延续，适量 Worker 与受控自动化即可 |
| 成果 | 完整工程包，能交 Codex，所有页面与按钮都可用 | 任务+API+页面矩阵+验收证据，按功能闭环迭代，不承诺本包已实现代码 |

## 对上两次计划的正式修订

1. 取消“单独新画简化的 AI Trading Terminal UI”。原先示意图只是粗略信息结构，不得作为实现目标；官方基线唯一为当前 r127/UI 截图。
2. 保留原有导航项（首页、行情、快讯、要闻、策略、链上、资产、授权、数据、更多），以及二级频道、九大策略、右侧快捷工具、图表全部组件；以后可以改善体验，不得减少能力。
3. Ace Agent 不是新独立平台，也不是单一 Chatbot。让其成为侧边操作中枢，跨页面分享上下文和 ActionCard。
4. “真实交易”从可选远期能力调整为 P0 安全修复后的正式主线：首先人工 CEX 现货小额真实单，其次 IBKR 股票，最后限定的策略自动化。
5. 旧 `PROJECT_BRIEF.md` 和 `AGENTS.md` 的交易安全规定保留为**默认保护与执行约束**，不能被理解成“永不实盘”。部分旧文档“先做所有研究再接券商”的次序被新路线修正，但必须先过 P0 安全门禁。
6. 现有策略和图表开发成果应当持续扩展，不为配合新开源前端替换代码。

## 事实范围与不确定性

- 本次审阅以 GitHub main 当前代码及项目已知对话/用户五张截图为基础，未宣称已经逐字查阅用户账户里所有历史聊天，也未进行对外实盘测试。
- 所有功能进度以仓库代码+可复核的测试与外部供应商响应为准，不以 README 规划文字当成真实上线证据。
