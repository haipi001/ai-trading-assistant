# 整体 UI 完善计划：导航、标签与 AI 核心工具栏

日期：2026-11-14
状态：实施中；进度与验证边界见 docs/acceptance/ui-workspace-20261114/。本文件不代表功能已完成。

## 目标与已确认约束

建立有序、流畅、高度自定义的跨市场终端。股票/ETF、加密CEX、Web3共享工作台，切换全局市场不得自动重排导航、关闭标签、替换固定页面或重置布局。通用栏由用户选择显示；市场专属页面仍保留自身上下文。保留现有功能代码和深链接。此前移除的上下文锁定横栏、AI助手横栏不恢复。

开发对象是新版 terminal-ui，不是根 index.html 旧版入口。运行目录为 /Users/lizekai/Documents/交易系统/terminal-ui；仓库镜像为 ai-trading-assistant/terminal-ui。修改以仓库源码为准，校验后同步到运行目录，禁止两份各自演进。嵌入面板来自 src 与 build:terminal 构建产物。

## 一、最终交互规则

### 导航与工作标签分工

左侧负责发现和打开功能；顶部只列出已打开工作页。默认分组为总览、行情、资讯、研究、资产、交易，底部设置。默认归属是展示方案，不修改原功能身份；支持自定义分组、组内和跨组排序、收藏、显示隐藏。支持拖动和键盘移动，菜单提供等价操作。所有原页面先建立映射，无法合理归类的保留在工具组，不强行删除或合并业务。

单击导航激活已有同实例页面；显式“新建实例”才能重复打开。同一图表允许不同市场和标的并存。标签显示短标题，必要时补充市场、标的；未保存、错误、固定状态有轻量标识。提供关闭、关闭其他、关闭右侧、固定、复制实例和重新打开最近关闭页面。固定标签不参与批量关闭。关闭含未保存编辑的实例时提供保存、放弃、取消；不得因切换标签而提交表单。

标签溢出使用横向滚动和全部标签列表，自动露出当前标签，不压缩成无法辨认的小块。不自动折叠已有标签，不限制用户打开数量；后台实例实施资源预算。

### 显示隐藏

设置 → 导航与工作区，提供标准、专业、自定义预设。预设只是可编辑起点，切换市场不自动切换预设。

分开设置：侧栏分组/页面可见性、顶部快捷栏项目、已打开工作标签。隐藏导航项不会关闭现有标签、禁用功能或清除数据；“隐藏并关闭”是独立操作。搜索仍可找到隐藏项并提示其状态，可直接打开或恢复显示。整组隐藏前说明影响，设置与恢复默认入口始终可访问。

提供设置搜索、批量显示隐藏、即时预览、取消预览、保存和恢复默认。恢复默认只重置导航展示，不删除研究、策略、订单、草稿或账户。布局导入导出仅包含允许的展示字段，不包含凭据或权限。

### 市场联动

每个实例可设置跟随全局、固定上下文、跨市场汇总；仅在页面能力支持时提供相应选项。右键菜单和页面设置承载操作，不新增常驻整条工具栏。

| 类型 | 全局市场切换行为 |
| --- | --- |
| 跟随全局且支持目标市场 | 保持标签位置及布局，切换数据上下文，恢复该实例目标市场的标的与筛选 |
| 跟随全局但不支持目标市场 | 保留原上下文及内容，显示“保留Web3上下文”等提示，不自动替换或发起不支持请求 |
| 固定上下文 | 保留市场、标的与账户绑定，仍复验当前身份和权限 |
| 跨市场汇总 | 保持明确的汇总范围，不跟随全局 |
| 订单及交易草稿 | 始终绑定原上下文，不自动迁移；新建交易草稿必须明确目标 |

市场切换不移动、隐藏或关闭任何用户标签。不默默选择股票或加密默认交易账户。首次缺少标的映射时要求选择标的，显示待选择状态，不猜测同名资产。固定页面的授权失效仍须降级或阻断操作，不冻结过期权限。账户退出时清空敏感运行态并隔离用户配置。

### 流畅切换与状态恢复

立即更新活动标签和焦点；已就绪实例恢复滚动、筛选、草稿、图表周期、分隔比例。采用有上限的实例缓存：前台保持活跃，后台暂停不必要轮询，超出预算先保存可恢复状态再卸载无未保存编辑的实例。关闭实例清理订阅、计时器和事件监听。

异步请求绑定实例ID、上下文版本和用户身份，取消旧请求并拒收迟到响应，避免Web3数据写入股票页。切换时保留明确标注的旧快照或加载骨架，不用空白闪烁掩盖状态。减少动态效果偏好下取消切换动画；键盘焦点保持可预测。

## 二、技术设计

保留 registry.js 既有 code、别名和 supportedMarkets；另建导航映射，避免改写自动生成内容。建立版本化配置：navigation（分组、顺序、隐藏项）、shortcuts、tabs（instanceId、featureCode、绑定方式、固定上下文、顺序、固定状态）、activeInstanceId、paneLayout。数据快照和凭据不进入展示配置。

实例身份不得继续只依赖“分屏位置:功能代码”，否则同页多实例会冲突；panel-host 锁定、消息路由、缓存与状态恢复统一使用稳定 instanceId。迁移旧配置时保留原排列与链接；未知功能代码进入待恢复列表，不使整个配置加载失败。校验重复ID、非法顺序和不支持的绑定方式。存储失败提示并保留内存操作，不谎报保存成功。

预计文件：terminal-ui/app.js、integration/panel-host.mjs、integration/context.mjs、integration/shell.js、shell.css、desk.css；新增 navigation-model.mjs、workspace-tabs.mjs、workspace-preferences.mjs 及相应测试。具体拆分随实现复核。src 仅调整嵌入实例生命周期与上下文适配，不修改交易执行逻辑。

## 六、右侧核心辅助工具与 AI 布局（并入实施范围）

### 定位与不可变规则

左侧用于打开完整业务页面，右侧是稳定、可配置的核心辅助工具层。右侧的工具选择、顺序、展开状态、面板宽度、绑定方式不随全局市场变化。核心是功能定位，不代表禁止用户隐藏工具；提供推荐默认配置，全部可自定义，更多/编辑入口始终可访问。

左侧研究页面承载完整资料、报告与历史；右侧AI助手承载当前任务的快捷研究与辅助操作。两者共享任务和材料标识，不重复创建孤立聊天记录。右侧不再默认堆放ETF、特色数据等整页入口，这类完整业务页由左侧承载，需要时从辅助面板“在工作页打开”。现有入口先逐项映射、保留搜索可达，验收后再调整默认可见性。

### 默认按钮规划

右侧采用紧凑纵向工具轨，AI置顶，中段放常用辅助工具，底部固定更多/编辑。按钮采用一致图标、可访问名称、悬停文字和当前展开状态；不靠陌生符号或仅颜色传达用途。推荐轨宽44–48px，图标18–20px，可点击区域至少40px。状态徽标只表示真实任务/提醒，不用装饰性红点。

| 顺序 | 按钮 | 点击后展示 | 默认显示与边界 |
| --- | --- | --- | --- |
| 1 | AI 助手 | 研究对象、材料清单、对话与分析结果、可执行的研究建议 | 默认固定；唯一主AI入口，按对象明确引用材料 |
| 2 | AI 任务 | 真实排队/运行/待补材料/失败/完成任务，进度、取消、结果入口 | 默认固定；与助手共用任务系统，不再做第二个同质聊天入口 |
| 3 | 提醒 | 价格、事件与任务提醒，未读、条件和管理 | 默认固定；无后台能力时说明仅本机会话有效 |
| 4 | 笔记 | 当前对象笔记与快速记录、来源引用、保存状态 | 默认固定；未保存编辑不随切换丢失 |
| 5 | 计算器 | 仓位、盈亏、风险预算等确定性计算，输入/单位/公式 | 默认固定；无AI必需依赖，不伪造实时价格 |
| 6 | 快捷下单 | 显式账户/标的/模式/草稿与门禁状态 | 默认收纳到更多；用户可固定，始终走既有风控和审批 |
| 7 | 市场快照 | 深度、资金流、近期资讯的辅助视图，可跳转完整页面 | 默认收纳到更多；股票/CEX/Web3能力分别校验 |
| 底部 | 更多/编辑 | 工具搜索、显示隐藏、固定/收纳、拖动与键盘排序、恢复默认 | 始终可访问；工具帮助和连接设置在此可达 |

默认按钮数量是初始方案，P0结合现有工具审计确认；任何新工具没有真实功能前不展示为可用。已有Ace六源分析与AI工作中心先归并为助手内的“分析模式”和任务视图，不丢失原能力、来源信息与研究历史；命名不应暗示尚未实际接通的数据源。

### 工具面板布局与行为

默认单个展开面板，点击当前按钮切换展开/收起；工具间切换保存各自草稿、滚动和筛选。提供固定展开及拖动调宽，推荐初始宽360px，最小320px；最大宽按视口约束，桌面尽量保留主工作区至少480px。窄屏改为覆盖式抽屉，保留关闭与返回，避免主区和工具区同时缩得不可读。精确断点由实际8851布局测量确定。

上部固定标题与操作，下方简洁上下文行，中部滚动内容，底部输入/主要操作。主次按钮明确，长报告不撑开工具轨。使用现有主题语义色和统一间距；轻量分隔、明确层级，不用大面积高饱和装饰。支持亮暗主题、文字缩放、键盘导航、焦点可见、Escape关闭与焦点返回。不能用额外常驻横栏重新占满页面。

固定展开表示布局偏好，不冻结权限；市场切换不关闭面板。用户显式关闭后保存关闭状态；若关闭含未保存编辑的工具，走保存/放弃/取消流程。允许后续扩展多工具并排，但首期不默认实现多抽屉叠放。

### 数据联动：当前页面、全局、固定上下文

每个工具独立选择跟随当前页面、跟随全局、固定上下文；计算器等无上下文工具不展示无意义的绑定选项。默认AI助手跟随当前页面，交易草稿固定创建时的上下文。工具标题下持续显示实际对象和绑定方式；主页面和工具对象不同时明确标识，不用仅一个“固定”图标解释。

当前页的定义是最近明确激活的工作页/分屏实例；打开工具、输入聊天或悬停不得改变该实例。启动AI任务时冻结输入快照；之后页面切换只改变新任务的上下文，不改变运行中任务或已展示结果。显示“结果来自ETH，当前页面AAPL”，由用户选择发起新分析，不把旧结果标成新对象。专属工具遇不支持市场时保留原对象并说明限制。

### AI 必须可读取、可分析、可展示

不得以聊天框存在或点击按钮有响应作为AI完成。为各页面提供结构化材料接口，列出允许读取字段：页面/实例ID、市场、标的、场所、周期、数据快照与时间、来源、筛选条件、选中条目、数据质量与缺失字段；账户与仓位仅按当前身份权限提供最小必需字段，不读取密钥、原始私钥或未授权资料。iframe通过既有可信消息通道传递，校验origin、source、instanceId、用户身份与上下文版本，不依赖抓取屏幕文本猜测数据。

助手需可展示：

1. 当前研究对象、绑定方式、后端及模型连接状态。
2. 已选材料的名称、时间、来源、可用性；允许查看、排除及刷新材料。
3. 可编辑任务输入与按页面能力提供的分析动作；缺资料明确指出，不假装就绪。
4. 请求中/排队/运行/取消/失败/完成等真实状态，避免将阶段结束当作分析成功。
5. 结果中的事实、推断、不确定性与缺失信息；引用可回到对应快照或原始材料。
6. 保存到研究、加入笔记、创建提醒、打开完整工作页等真实后续操作与成功反馈。

模型不可用时给出配置入口和可理解错误；拒绝无效结构化输出，不生成模拟“完成”结果。确定性数据摘要可独立展示并标为摘要，不能冒充模型分析。报价过期、账户未验证、数据不足必须显示具体限制。重试针对失败请求，保存/创建类操作避免重复产物。任务和结果按用户、实例、上下文隔离。

AI仅建议、研究和生成受控草稿，不直接执行交易或绕过权限、风险与审批；提示中的工具调用不允许任意访问账户。若缺少真实模型或数据配置，记录为集成阻塞并保留可验证的界面状态，不宣称AI已可用。

### 设置与持久化扩展

设置 → 导航与工作区中分设“左侧导航”“顶部标签”“右侧工具栏”，三者互不覆盖。工具轨底部编辑入口直达右侧设置。

配置扩展为 toolRail（可见、顺序、固定/更多）及 toolPanels（工具ID、展开/固定展开、宽度、绑定方式、固定上下文、可恢复视图状态）。未保存文本按专门草稿机制处理，不把敏感账户材料塞入布局导出。恢复右侧默认仅影响右侧展示，不能清除左侧或业务内容；导入时验证工具ID、宽度和绑定能力，未知工具保留为可恢复配置。
