# 通用策略与全页功能演示

目标：策略规则跨市场和页面复用；其余页面无需凭证即可通过模拟数据体验展示与交互。新版入口为 `terminal-ui/index.html`，不使用根 Vite 旧界面作为入口。

## 实现

- 68 个注册业务入口均提供“功能演示 · 模拟数据”切换，可返回原业务页。全局“通用策略 / 页面演示”打开当前业务面板的演示；原生终端页原有模拟界面保留，全局入口直接进入策略演示。
- `src/demo-strategy-model.js` 提供共享规则校验和确定性回放，支持均线趋势、区间突破、价格条件。股票、CEX、链上使用同一规则引擎，输入为各自独立模拟价格。
- 编辑名称、观察周期、价格条件、仓位、止损止盈、手续费和初始资金。策略支持保存、载入、复制、删除；独立演示策略库跨页面复用，多个面板通过 storage 事件同步列表。
- 回放展示权益曲线、收益率、最大回撤、费用、未平仓数量和模拟逐笔记录。信号只使用前一日及以前数据，在下一日收盘模拟成交；持有期间估值计入权益。切换场景保留规则并使旧结果失效。
- 行情、资讯、研究、链上、资产、授权、数据和工具采用对应分类样例；深度、资金流、合约、盈亏日历、流水、风控、授权步骤、安全说明和储备有专用样例。提供筛选、详情、演示动作和本页重置。
- 演示模块动态加载，沿用终端亮暗主题和强调色。策略表单在窄面板单列排列，长表格自身滚动。
- 保存、删除、回放写入独立本地演示审计记录（最多100条），不会写入后台账户或订单。

## 本地验证

```sh
node --test terminal-ui/tests/*.test.mjs
TERMINAL_FEATURE_OUTDIR=terminal-ui/features TERMINAL_SOURCE_DIR=../terminal-ui/ npm run build:terminal
python3 -m http.server 8850 --bind 127.0.0.1 --directory terminal-ui
```

访问 http://127.0.0.1:8850/#R038 ，点击“功能演示 · 模拟数据”。无需后台凭证。

浏览器验收脚本、JSON及截图见同目录 `strategy-demo-20261114/`。测试使用拦截外部请求的独立浏览器会话；不修改既有账户和业务草稿。68入口巡检在独立功能面板验证渲染与详情/回放操作；完整终端另验9类页面、策略保存跨页复用、场景切换、回到业务页及390px窄面板。

## 适用范围

固定72日生成数据用于产品演示，不是实盘功能或真实历史回测。日线收盘成交未建模滑点、盘中触发、流动性和市场冲击。策略仅做多，最多一笔持仓。页面动作仅影响演示会话；演示策略保存在浏览器本地，不代表后台策略已创建或启动。实盘保持关闭，真实研究材料与演示数据不互通；既有后台策略、订单审批和Paper工作流保持原有边界。

- 终端 Node 测试：179/179 通过，其中本次新增8组策略与演示数据测试。
- 终端生产构建通过；保留既有大包体积提示。

- 完整终端覆盖9类业务页的筛选、详情、演示动作、重置、返回业务页；策略保存、载入、复制、删除、刷新后跨页复用、场景切换保留参数并失效旧结果通过。
