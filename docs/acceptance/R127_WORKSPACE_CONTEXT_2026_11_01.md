# r127 T1增量：工作区身份与研究历史隔离

本轮为允许独立推进的非破坏性UI切片；T0门禁与完整113任务仍未完成。未启用实盘、未部署或付费调用。

## 实现

新增workspace-context.js，并在现有主终端和FloatingAIChat中使用。上下文记录page/tab、资产类别、标的、交易所、周期、登录主体、资料来源、可选账户与执行模式以及单调版本号。身份不变的行情刷新不增加版本，身份/来源/登录主体切换增加版本。未选择交易账户时mode/account_id保留null，不把公开真实行情误称LIVE执行。这是渐进兼容层，尚未声称完全满足原包最终Schema或服务端Workspace存储契约。

切换工作区取消行情/资讯附带勾选并给出重新选择提示。对话仍可查看，但自动附带历史仅包含相同工作区身份；切回原工作区可再次使用其历史。异步回复保留发起时的身份和版本，不标为切换后的新对象。登录主体变化也隔离自动历史。已有消息来自旧版本而没有身份标签时，不自动附带。

图表通过既有footer回调额外传递timeframe；原导航、频道、图表工具、研究控件及布局均保留。现有模型API契约未变，版本元数据暂留客户端；不伪造后端任务ID或后台进度。
