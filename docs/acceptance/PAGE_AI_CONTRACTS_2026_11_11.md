# 二级页 AI 动作与材料审阅 — 2026-11-11

本轮完整读取目标附件，以 terminal-ui 为根基继续推进逐页 AI。上一轮有代码修改及实际 HTTP 证据，属于 progress。完整目标仍 active，以下不是功能全量完成声明。

## 行为

FunctionRegistry 为68个二级页生成204条动作定义：别名、适用市场、允许的数据字段、必需材料、预期产物、研究权限、失败状态及资料跳转目标。集中策略位于 `integration/page-ai-actions.mjs`，生成命令为 `node terminal-ui/scripts/sync-page-ai-registry.mjs`；重复生成已验证字节稳定。九类策略保留各自的数据检查点，DEX跟单仅链上只读研究，CEX跟单及游资跟踪各自保留市场范围。

AI上下文抽屉显示本页材料需求与限制、预期产物和资料入口。128条定义需要人工审阅（包括68条仅整理缺口的动作），76条分析／风险动作因材料还没有接入AI而明确未就绪。当前已有的材料通路是原始图表OHLCV、后端缓存资讯、显式选中的链上只读证据；这些只是可选通路，不能把“已定义”或“通路存在”当作当前材料有效。资讯缓存并非按当前子栏目筛选，界面与问题均说明该限制。

原生模拟页面不把随机数字送作证据。其分析动作要求转到业务资料页，缺口动作只在本地准备说明，仍需在业务面板重新选择。持仓、订单、门禁、深度、资金流、脚本/回测、经济事件等专用材料尚未绑定时，不能通过通用提问伪装成已经读取。手动原功能不受这些AI按钮状态影响。

准备后的动作绑定具体面板、市场、标的、场所、账户/钱包、周期、执行模式及contextVersion；嵌入桥验证同源父窗口、实际功能与上下文，再按规范重建动作，拒绝伪造材料要求。发送前再次核对；切换后保留旧准备及失效提示，不会悄悄丢弃限制后自动作为新问题发送。用户可明确取消本页动作限制转为手动提问。必需材料不可取消后继续保留该动作，也不能偷偷增加未声明材料。没有自动模型调用、参数应用、脚本执行、审批或订单提交。

实际返回仍是已有的结构/身份/引用校验研究回复；预期的专门筛选草稿、参数、脚本差异等不等于已有业务产物，更不是独立报告评估或交易可信数据。原市场/链上研究快照与历史机制继续沿用。

补齐AI状态权限：即使已有配置，只读角色缺少readiness:write时，status也返回can_request=false与ai_permission_required。真实路由测试确认GET状态与POST403一致，未构造Provider。该状态修复未改变任何交易角色/权限。
