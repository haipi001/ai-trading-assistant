# 新终端黑白主题与风格统一 · 2026-11-05

状态：主题基础设施与代表场景已验证；完整功能、所有动态控件及视觉验收仍未完成。

用户要求：注意风格一致性，黑白一致且可切换。以terminal-ui的终端结构、字体与密度为基础，不恢复旧版外壳。

## 实现

- 顶栏黑/白按钮负责全局外观，本机terminal-appearance-v1保存偏好；TH继续切AMBER/ICE/TOXIC强调色。
- integration/appearance.mjs管理外观，appearance.tokens.css由src/terminal-appearance.js生成同一套语义颜色。主框架与嵌入页共享面板、文字、边框、状态和强调色。
- scripts/terminal-theme.mjs只在Vite嵌入构建中生成带html[data-terminal-color-mode]作用域的旧样式覆盖；保留原规则与media结构，不改旧版独立CSS。原静态写死颜色映射到语义角色，SVG画线与指标配色保留。npm run theme:terminal可重生成主框架覆盖；build:terminal自动执行。
- 主题消息校验同源与发送窗口；黑白切换仅发外观包，不修改交易上下文、不重建整个业务App。设置弹窗的“应用主题”与顶层双向同步。
- 图表默认背景、坐标文字、网格、边框和空心K线跟随主题，使用applyOptions更新；用户显式自定义图窗背景保留。旧版独立图表默认浅色行为保留。
- 统一按钮/输入框及焦点样式，保留涨跌语义。补齐侧栏长文本换行；AI抽屉根据上下文工具栏实际高度定位；分屏业务框使用剩余高度，保留锁定控制行。

浏览器验证图表、设置弹窗、策略笔记与AI抽屉、新闻和资产页；四分屏同时放入R009/R026/STR0/R045，逐个读取根节点dark/light属性与截图核对。设置中切深色，顶栏一起变黑；顶栏切白，弹窗也切白；刷新后白色保留。截图位于terminal-ui/evidence/theme-*-20261105.jpg。
