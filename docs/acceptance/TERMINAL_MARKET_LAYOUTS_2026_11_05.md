# 新终端各市场独立布局 · 2026-11-05

状态：此增量已实施并完成所列验证；完整前端整合目标继续。

## 实现与接口

股票、CEX、Web3 分别记住单/双/四屏、焦点、功能、原终端标的、行列分割比例、四个面板槽及锁定上下文。初次进入股票/CEX默认单屏图表，Web3默认单屏链上研究。市场切换恢复只读，保留原账户身份选择但不恢复执行权限；渲染失败回滚原布局与状态，仍保持只读。注销清理隐藏市场锁定账户和钱包。

本机自动保存、导出/导入、恢复前备份和云端工作区均携带 marketWorkspaces；旧版 schema1 文件缺此字段时仍可导入。文件总大小不能超过512KB，非法隐藏面板、重复锁、未知市场/功能均拒绝。恢复失败回滚市场布局映射，避免只恢复当前画面而损坏其他市场记忆。

GET/PUT `/api/v2/workspaces/{workspace_id}` 的 layout 新增可选 market_workspaces 数组，最多3项、market唯一。每项包括 market、panel_count、focused_panel、last_function_code、last_terminal_symbol、split_columns/rows、恰好4个 panels（panel_id 0–3）及 locked_contexts（最多300个、key唯一）。每个隐藏面板/锁的账户与钱包沿用后端归属、市场与链校验；权限、版本CAS、workspace.saved审计不变，使用既有JSON列，无数据库迁移。

修复补测发现的云端恢复缺陷：根 panels 只含可见槽位，恢复时现在合并当前市场完整布局，保留未显示的面板、main锁及其他隐藏锁；不能在下一次市场切换中把完整记忆覆盖为裁剪后的布局。
