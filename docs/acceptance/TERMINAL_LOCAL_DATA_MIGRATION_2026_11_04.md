# 新终端本机数据迁移与导航证据 · 2026-11-04

状态：增量实现、受控验证通过；完整整合目标仍未完成。

## 实现

旧前端新增 local-data-migration.html；新终端功能包同时生成 features/local-data-migration.html。入口在新终端研究抽屉的工作区区域。旧前端新增 start.command，可启动3002；旧版不运行时先启动再从原浏览器地址导出。localhost和127.0.0.1，以及不同端口的存储独立。

local-data-migration.js 仅处理23个明确列出的研究/偏好键：自选、图表布局/画线/快照/显示偏好、策略笔记/草稿、脚本草稿库与编辑缓冲等。连接凭据、后端会话、原本地模拟订单不迁成真实账户或账本。文件保留用户的研究文字和脚本，始终在本机处理。

数据包上限8MB、条目上限3MB；脚本和布局继续使用原领域校验器。拒绝未知存储键、已知凭据字段、不安全对象键及损坏结构。笔记与脚本代码不会自动运行或发送模型。

预览显示新增/相同/冲突；冲突默认不选中。应用前再次比较本机原值，防止预览后其他页面修改；写入前保存可恢复备份，部分写入失败回滚。脚本库与编辑缓冲、布局目录与当前布局标识做关联校验；不影响无关条目的单独迁移。原本地订单面板打开偏好恢复为关闭。

## 发现并修复的实际缺陷

- Strategy组件在tab初始化时会把嵌入传入的策略类别重置为1，使STR0等入口落到智能套利。增加嵌入边界后保留外层目标类别；旧版独立入口仍沿用原导航初始化。
- 笔记“AI分析”原来用本地模板直接写“AI已完成”。现改为预填真实研究面板的问题，由用户审阅并发送；历史分析/示例标注来源未验证。未自动请求模型或生成已验证结论。
- 原followed-traders存储为字符串数组；迁移策略按实际源码使用字符串数组，非对象数组。
