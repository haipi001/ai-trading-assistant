# TERMINAL — 本地可运行行情工作站前端

一个真正能跑、能输入的终端前端（纯静态，无构建、无依赖、无网络请求）。
本项目接手既有静态 UI，并补充全功能目录、常驻工作区导航与分屏控件。安装包的静态检查不能证明原版全部界面布局，因此本项目属于终端风格 UI 重建，未宣称与原软件逐屏一致。

## 打开方式

**方式一（最简单）**：双击 `index.html`，Safari / Chrome 直接打开即可。

**方式二（本地服务器，推荐用于调试）**：

```bash
cd 该目录
python3 -m http.server 8848
# 浏览器访问 http://127.0.0.1:8848/
```

或双击 `start.command` 自动起服务并打开页面。

## 功能页

- `WEI` 全球指数（10 个）
- `W` 自选监控（可增删，实时刷新，数据持久化）
- `TOP` 头条新闻（12 条，可点进标的）
- `DES` 证券概览：报价、涨跌、买卖价、区间、简介、迷你走势、6 档盘口深度、逐笔成交流（TIME & SALES）
- `GP` 蜡烛图 + 十字光标 + MA20/60 + BOLL(2σ) + 副图 VOL / RSI(14) / MACD(12,26,9) + 5M/15M/1H/1D 周期切换（Canvas 自绘，支持 HiDPI / 自适应）；四种主图类型 CANDLE（实体 + 影线）/ BAR（OHLC 棒）/ LINE / AREA，可切对数价格轴，选择随档案存档
- `HP` 5 分钟历史价格表
- `N` 单标的新闻
- `MOST` 成交最活跃
- `SET` 设置与档案：FEEDBACK（告警音 / 桌面通知 + 授权状态）、PERFORMANCE（后台暂停 tick / 表格密度）、APPEARANCE（三套主题 / 品牌图标 16–256px）、PROFILES（当前档案、切换、新建 / 改名 / 删除）、EXPORT（图表 PNG、表格 CSV、打印）、ABOUT（安装器复刻入口、功能指南）
- `PORT` 组合：总权益 / 现金 / 市值 / 未实现盈亏卡片 + 持仓表（成本、现价、市值、P&L、收益率、一键平仓）+ 下单票据 + 风险面板（组合 Beta、年化波动、1 日 95% VaR、前三大集中度、多空敞口条）
- `TRD` 成交簿：FILLS / 买入名义 / 卖出名义 / 已实现 P&L / 现金 + 逐笔明细
- `OPT` 期权链：Black-Scholes（r=4.2%）定价，ATM 为中心 9 档行权价，微笑波动率、Call/Put Delta 与 OI、ITM 着色、到期切换
- `GOV` 美债收益率曲线：1M–30Y 共 11 档，Canvas 绘制当前曲线（实线）与昨日曲线（虚线）、网格与倒挂区间底色，2s10s / 3m10y 利差、曲线形态判定（INVERTED / FLAT / STEEPENER）
- `FX` 汇率矩阵：8 币种（USD/EUR/JPY/GBP/CHF/AUD/CAD/CNH）交叉盘 8×8，单元格为主币种每日涨跌双行，行首列首高亮，对角留空；下方现货换算器（金额 + FROM/TO 双下拉 + CONVERT / SWAP，交叉汇率折算）
- `CMDT` 商品远期曲线：CL / GC / HG 三品种，前 10 个合约月结算价折线（近月实心、远月空心）+ 曲线形态判定（CONTANGO / BACKWARDATION / FLAT）+ 逐月表格（月差、累计价差、年化 carry），root 切换 chips
- `ECO` 经济日历：12 条事件，按重要度三档着色，含 Survey / Prior / Actual 与 RELEASED / DUE / SCHEDULED 状态
- `COMP` 同业对比：以当前标的所属板块自动取可比公司，含板块 P/E 中位数、市值排名、相对基准超额（pp）与 P/E 折溢价
- `ORD` 挂单簿：WORKING / FILLED / CXL 三态，含单据号、创建时间、方向、类型、数量、限价、与现价距离、成交价与撤单按钮，顶部汇总在挂笔数与名义金额
- `ALRT` 预警管理：`>` / `<` 双向条件、票据录入、触发状态与触发时间、距触发的百分比距离、删除按钮；触发时状态栏提示并播放提示音（仅本地合成音）；页内含 TRIGGER LOG 触发日志（触发时间、条件、成交价、超出幅度、PIN 回写命令行）与 CLEAR LOG
- 分屏工作区：`LAY 2` / `LAY 4` 把四类面板并排，每个面板独立保存功能与标的，点击面板头或用命令重定向焦点面板；分屏状态下顶栏命令只作用于焦点面板。分屏中间有可拖拽分隔条（垂直/水平），比例 20%–80% 钳制、双击复位 50/50，比例随布局写入 `localStorage`。
- 图表画线：GP 图右上角 TREND（两点趋势线）/ H-LINE（水平价位）/ UNDO / CLEAR，按「标的 + 周期」分别存储，重绘与切换周期后仍保留
- CSV 导出：成交簿、持仓、挂单、预警均可在对应页面点 `CSV` 按钮或命令行 `EXPORT <KIND>` 导出（带 BOM，Excel 直开不乱码，字段含逗号自动加引号）
- `FA` 财务分析：5 年损益表（营收 / EBITDA / 净利率 / EPS）+ Canvas 双轴柱线图（营收柱、EBITDA 折线与净利率折线）+ 估值与质量比率表（P/E、P/S、EV/EBITDA、ROE、ROA、净利率、负债率、Beta）；非股票标的给出提示而不报错
- `EQS` 股票筛选：对本地 10 只股票按市值排序，页内 SCREEN BUILDER 支持逐条增删条件、AND / OR 组合、APPLY、命名保存（每档案最多 8 组，可一键载入或删除），支持条件表达式 `PE<30`、`MCAP>500B`、`CHG>=1.5`、`PX<200`、`VOL>1e7`，字段 `PE / MCAP / CHG / PX / VOL`，运算符 `< > <= >= =`，后缀 `K / M / B / T`；多条件用空格分隔（AND），筛选 chips 可一键切换，无法解析的词在页脚提示并忽略
- `FLDS` 字段字典：42 条字段助记符（`PX_LAST` / `PE_RATIO` / `CUR_MKT_CAP` / `YLD_YTM_MID` 等，含 PRICE / ANALYTICS / FUNDAMENTAL / CORPORATE / RATES / REFERENCE 六类）的类型、分类、说明与所喂给的终端列，支持按助记符 / 分类 / 说明全文模糊检索，分类 chips 一键过滤
- `HELP` 命令参考（v1.4，已补 ORDER / ALERT / EXPORT / LAYOUT / ANALYTICS 章节）

URL hash 可直达任一页：`index.html#GP/AAPL`、`index.html#DES/NVDA`、`index.html#PORT`、`index.html#TRD`、`index.html#OPT/AAPL`、`index.html#GOV`、`index.html#FX`、`index.html#ECO`、`index.html#COMP/AAPL`、`index.html#ORD`、`index.html#ALRT`、`index.html#FA/AAPL`、`index.html#EQS`、`index.html#FLDS`、`index.html#LOGIN`。

## 布局规范

- 所有面板式视图（GOV / FX / ECO / COMP / EQS / FLDS / SRCH / PORT / TRD / ORD / OPT / ALRT / DEPTH / MAP）共用同一内边距基线 `12px 16px 20px`，窄屏（≤680px）统一收为 `10px`，保证切换功能码时标题、卡片、表格的左边线不跳动。
- 新闻列表（TOP / N）为四列栅格 `时间 / 标题 / 标的·板块 / 展开箭头`，展开正文以 `grid-column:1/-1` 独占整行，箭头由 ▸ 切到 ▾。
- 盘口（DEPTH）为 `1.15fr : 1fr` 两栏：左价格阶梯 + 失衡条，右逐笔成交 + 报价合计；≤900px 折叠为单栏。
- 热力图（MAP）按板块分列，列宽均分、方块高度随市值（flex-grow）、底色随涨跌幅，七个板块列等高铺满可用高度。
- 筛选条（TOP / N / SRCH）输入框占满剩余宽度，聚焦时描边转为强调色；无命中时在列表/表格下方给出 `NO … MATCH` 空态提示。
